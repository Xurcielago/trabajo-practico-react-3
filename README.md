# Mantenimiento IPF

Esta aplicación permite registrar y seguir incidencias de mantenimiento en instalaciones o aulas. Está pensada para que usuarios del centro puedan reportar problemas como fallas eléctricas, fugas de agua, mobiliario roto o equipos averiados.

## ¿Cómo funciona?

1. El usuario accede a la pantalla principal y crea un nuevo reporte.
2. Completa un formulario con título, descripción, aula y categoría del problema.
3. Puede añadir información extra como una foto, ubicación aproximada o escaneo del QR del aula.
4. Cuando se guarda el reporte, queda visible en la lista principal con su estado actual: pendiente, en curso o resuelto.
5. La app también muestra avisos y permite consultar el historial de incidencias, además de gestionar los permisos necesarios para cámara, ubicación y notificaciones.

## Características principales

- Registro de reportes de mantenimiento.
- Categorización por tipo de problema.
- Adjuntar foto y ubicación del desperfecto.
- Escaneo de QR para identificar el aula.
- Seguimiento del estado del reporte.
- Avisos internos dentro de la app.
- Control de permisos del sistema.

## Nota

Esta versión funciona como una app móvil local de gestión de incidencias: los reportes se gestionan dentro del estado de la aplicación y no requieren una base de datos externa para su uso básico.
